(* = best in category)

KEY FINDING: Combining ROI cropping, illumination correction, and
non-destructive green-channel enhancement (P7) produces the BEST
ordinal classification agreement (QWK 0.7582) of the entire study,
but the WORST segmentation Dice (0.6645, below even baseline P0).

This demonstrates that these preprocessing techniques are NOT simply
additive/complementary -- combining them shifts the model's learned
representation toward features useful for global disease-severity
judgment (favoring classification) at the expense of fine-grained
pixel-level lesion boundary precision (hurting segmentation,
particularly the already-weak SE lesion type). This is a genuine,
non-trivial interaction effect between preprocessing steps, not simply
"more preprocessing = better."

PRACTICAL RECOMMENDATION:
- If segmentation quality is the priority: use P3 (illumination
  correction alone, no green enhancement)
- If classification/DR grading ordinal agreement is the priority: use
  P7 (the full combined pipeline)
- No single preprocessing configuration dominates both objectives
  simultaneously -- this reflects a genuine task-level tradeoff, not an
  implementation shortcoming, and is consistent with the broader
  pattern seen throughout this project where architectural and
  preprocessing choices repeatedly show a Dice/Kappa tension rather
  than both improving together.
