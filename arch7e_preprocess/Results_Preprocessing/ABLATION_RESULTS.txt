KEY FINDINGS:
1. Validation scores were systematically and severely inflated across
   all presets (e.g. P3: val accuracy 0.90 vs real test accuracy 0.60;
   P4: val Kappa 0.9356 vs real test Kappa 0.7412). This confirms a
   consistent pattern throughout this project: validation drawn from
   augmented training data cannot be trusted as a proxy for real
   generalization -- only held-out test-set evaluation is reportable.

2. No single preprocessing preset dominates all metrics -- there is a
   genuine segmentation/classification tradeoff:
   - Illumination correction (P3) best serves segmentation, especially
     the weaker SE lesion type (+0.033 Dice vs baseline)
   - Green-channel CLAHE (P4) best serves classification (+0.057 QWK
     vs baseline), likely because green-channel contrast better
     highlights the global retinal patterns relevant to DR severity
     grading, even though it slightly weakens lesion boundary detail

3. Sharpening (P5) was net negative on QWK, confirming the faculty''s
   caution against over-processing: amplifying high-frequency detail
   did not help lesion boundaries and instead introduced noise that
   hurt ordinal classification agreement.

RECOMMENDATION: If segmentation is the priority, use P3. If
classification/DR grading is the priority, use P4. A combined
P3+P4 pipeline (illumination correction + green-channel CLAHE together)
would be a natural next ablation to test whether their benefits combine.
